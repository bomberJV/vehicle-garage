# Project priorities

The private [portfolio priority hub](https://github.com/bomberJV/brandon-studio/tree/priority-hub/priorities) tracks this project alongside the website. Read the [agent handoff](https://github.com/bomberJV/brandon-studio/blob/priority-hub/priorities/AGENTS.md) to find, claim, add or update work. Agents sharing a GitHub login use a unique run name for reservations.

Work in the repository that owns the code. Link its PR and verification to the shared issue. Check for an existing project issue or garage source key before creating another task.
